## KD-001

**场景。** Windows 桌面 VS Code 1.143.1，正常安装 VSIX 并使用隔离配置。
在全新 Webview 中打开普通长度文档，从正文顶部用可信滚轮连续滚到 Live 中的
40 节点 ELK 宽图。使用 [Mermaid 冷渲染测试的普通文档宽图夹具](../scripts/test-mermaid-reading-generation-production.ts)，
沿用随图块位置调整的滚轮序列。基线的 Live 滚动区域约为 1354 × 857 CSS 像素，
设备像素比为 1.5。采用自然冷启动，保留产品自身的提前准备，不额外延迟引擎加载。

**指标。** 按帧观察图块进入视口到实际 SVG 节点首次可见的耗时，要求图在滚动期间显示。
性能目标仍为 **500 ms**，严格大于该值计为一次超时。

**基准。** 冻结 0.4.6 的产品提交为 `f125ed6646d70948b2af2a8a95107d4fa8ad5a20`，
VSIX SHA-256 为 `7146a86fde4d3a664fae892d8e0f5a0a3a0f7397a99bf7a2043e5124b0297892`。
同机同流程两批样本如下。

| 批次 | 入屏到图可见（ms） | 超过 500 ms |
| --- | --- | --- |
| 初测 | 316.5、829.5、971.5 | 2 / 3 |
| 复核 | 129.6、460.5、340.2 | 0 / 3 |

参考结果是 **六次中两次超时，最慢 971.5 ms**。这是验收对照样本，真实使用中的频率
和长尾根因仍未确定。

**后续处置。** 当验收再次遇到这项超时时，收集同一候选、同一可比环境和同一操作流程的
六个有效冷启动样本。已有适用样本可以复用，首次超时也计入。保留全部样本及参考包的
环境、输入和测量条件。条件无法对齐时，以固定参考包做同机对照，取得可比证据后再作判断。
保留固定参考包和历史记录，后续候选的结果不抬高接受范围。

- 六次中超时不多于两次、最慢不超过 971.5 ms，且适用的行为验收均满足时，可按已知
  缺陷接受。最慢耗时或超时次数超过基准时，按回归处理。
- 其他模式、文档规模、图形或独立测试环境的超时按各自的验收规则处理。图未显示、
  滚动跳位、正文几何变化或输入异常仍属于独立失败。

## KD-002

**场景。** 在 Windows 本机运行 [Mermaid 冷渲染测试的窗口化 Preview 高图夹具](../scripts/test-mermaid-reading-generation-production.ts)。
使用 Edge 158.0.4370.33、Bun 1.4.2、1280 × 900 CSS 像素视口，以及每次新建的无头浏览器配置。
连续发送可信滚轮输入，对 16 节点纵向 ELK 流程图，在图进入视口后才放行实际 Mermaid
引擎入口请求。使用同一夹具单场景采样，保留原命令的滚轮、加载和行为断言。

**指标。** 从图块进入视口到滚动期间首次看到实际 SVG 节点。性能目标仍为 **500 ms**，
严格大于该值计为一次超时。滚动位置、后续正文几何、图形比例、占位裁切和滚动结束后的
完整展示均须满足原验收要求。

**基准。** 使用冻结的 0.4.6，产品提交为 `f125ed6646d70948b2af2a8a95107d4fa8ad5a20`，
VSIX SHA-256 为 `7146a86fde4d3a664fae892d8e0f5a0a3a0f7397a99bf7a2043e5124b0297892`。
正式版 0.4.5 在同场景也曾超时。参考包的六次单场景样本如下。

| 批次 | 入屏到图可见（ms） | 超过 500 ms |
| --- | --- | --- |
| 定向复测 | 356.5 | 0 / 1 |
| 同场景诊断 | 563.9、661.0、1025.8、1434.2、393.5 | 4 / 5 |

参考结果是 **六次中四次超时，最慢 1434.2 ms**。此前完整命令的超时保留在原始验收报告中。
这些样本衡量强制冷启动下的行为。实际使用中滚入和远跳时，引擎请求由产品调度。

**后续处置。** 复验时收集同一候选、同一可比环境和同一操作流程的六次有效冷启动样本。
可复用条件一致的样本，首次超时也计入。保留原始自动断言、失败报告和逐帧证据。环境或
夹具无法对齐时，用固定参考包做同机对照。后续候选的结果不抬高接受范围。

- 六次中超时不多于四次、最慢不超过 1434.2 ms，且行为验收均满足时，可按已知缺陷接受。
  任一指标确认变差时按回归处理。
- 自然滚入、远跳、其他模式、图形或独立环境的超时按各自验收规则处理。图未显示、
  滚动跳位、正文几何变化或输入异常仍属于独立失败。
