# Mermaid 与块状公式编辑测试

## 原生块交接与局部更新

块的编辑呈现以同一份呈现选区为准：主键按住时，原生光标可以先移到目标正文，但旧块的源码、左右图形和留白保持到释放；释放后，目标正文接收输入，旧块一次性回到阅读态。方向键越过块边界直接完成交接，Escape 的显式阅读焦点规则保持。局部更新同时清理旧呈现选区和新原生选区，不以“原生光标已经移动”为由遗留编辑结果。

公式的编辑结果附着在闭围栏后的物理行，局部替换范围包含这个附件。该规则同时适用于 `$$`、TeX 围栏，以及列表、引用和脚注结尾，避免源码已收起但第二份预览仍在。附件检查先用缓存的起止行排除远处公式，再查询相交块的物理行，保留局部操作的行读取预算。

这些路径也用于结构复杂的中等文件，并不只在约 1 MB 时启用。`block-editing-interaction-uat.md` 的只读复核样本为 81,559 B、1,927 行、49 个代码围栏；C36 在修改前可复现公式结果残留，修复后同样的键盘移出和鼠标交接正常。未改变文档压力阈值或打开方式。

`bun scripts/test-block-editing-handoffs.ts` 已接入 `test:rendered-source`。它以普通短文档、49 围栏的富内容文档和长文本三种条件检查 22 组交接：原生公式、TeX、引用／脚注、HTML、普通／折叠代码、上下／左右 Mermaid 及窄窗口。检查包含真实数字输入后立即离开、按住期间的布局和侧边图形 DOM、释放后的唯一结果、原生源码行号、目标正文位置，以及交接不额外修改源码。`--handoff-case=rich/mermaid-side` 可单独运行高图左右交接。

高 Mermaid 的向下退出另记录 Chromium compositor 的实际 PNG 帧，使用不改变几何的见证色检查下方正文不消失或跳动。见证色绘制后才开始录制，并随 CodeMirror 原地属性更新恢复；不把 RAF 回调中尚未完成的测量误当成已绘制闪烁，也不依靠会主动触发编辑器测量的光标坐标采样掩盖问题。截图及失败原始帧保存在忽略目录 `.local/block-editing-acceptance/`。这是生产编辑器的独立浏览器验证，不代表原生 VS Code 窗口验收。

## 测试范围

范围包含 Mermaid 的主文档源码编辑区，以及独立 `$$` 围栏公式、`math` / `latex` / `tex` / `katex` 代码围栏的源码、即时结果和外层文档之间的交接。四个 TeX 语言别名与块状公式共用组件，公式直接使用主文档编辑器，使用原生编辑路径，不提供手动块内模式按钮。普通代码块作为留白、行号和工具栏外观的对照。

## 可重复运行

先构建本地运行资源，再执行独立的源码区测试包：

```powershell
rtk bun run build
rtk bun run test:rendered-source
```

前缀单元测试已接入 `test:unit`；完整源码区测试包已接入 `test:browser` 和 `test:targeted rendered`。浏览器使用临时独立配置，不操作用户打开的文档，不写系统剪贴板。

人工检查文档为 [rendered-block-source-uat.md](../scripts/fixtures/rendered-block-source-uat.md)，包含相邻块、普通代码对照、嵌套列表、引用内列表、脚注、清空恢复、多色饼图和公式。

Mermaid 分栏更新定向回归：`rtk bun scripts/test-mermaid-split-refresh.ts`（已接入 `test:mermaid-presentation`）。真实生产编辑组件使用可控制完成时机的渲染器，检查连续输入合并、更新期间保留旧 SVG、相同内容与主题缓存、过期结果拒绝、错误恢复、主题切换和销毁。分栏复用图形呈现控件，输入合并等待为 80ms；相同源码的装饰刷新不重复渲染或重置等待。源码暂时不完整时保留最后有效图并显示错误提示，恢复渲染也不清空旧图；首次渲染失败仍展示源码和错误。只改节点文字仍需重新排版，因为文字尺寸可以改变节点和连线布局。

2026-10-12 真实 Mermaid 运行时的三节点文字修改对比：一次更新从约 228ms 降至 103ms，图形实际渲染分别为 35ms / 36ms；缩短的是呈现等待，不代表 Mermaid 布局计算本身提速。长文字节点宽度从 180 增至 260，验证重新排版；延迟完成用例中旧图持续可见，无加载行。这是本机独立浏览器的定向证据，不是完整长测或原生 VS Code 实例测量。

同日追加原始长文档检查：在 4 倍 CPU 限速下，三节点图插入一个数字曾等待约 1.3～1.8s。后台预加载先于交互更新启动，且 Mermaid 内部让出线程时全文派生装饰重建插队。现在编辑后后台预加载等待 200ms，取消过期预加载的独立资源租约；取消只影响无人继续使用的渲染，仍有前台等待者的共享工作继续完成。已有图形更新跳过额外的初始化让步，全文派生刷新等待分栏的合并等待与图形绘制后再执行。最终独立复测：正常条件约 140ms，相同限速约 437ms；CPU 限速仅用于复现，不能视为原生窗口的固定时延承诺。新增调度等待、取消及共享等待者回归；首次加载让步和连续输入合并保持。

## 组合条件

Mermaid 输入矩阵为 6 种容器 × 520px / 1100px，共 12 组。容器为普通段落、列表、二级列表、引用、引用内列表、脚注；图形采用真实 Mermaid；另外检查上下／左右切换、首次选择、拖动比例、输入期间布局固定及窄面板回退。每组还切回预览核对文档未被改变。

公式独立矩阵为相同 6 种容器 × 520px / 1100px，共 12 组。每组检查点击进入、四个方向进入与离开、上源码下结果、主文档选区与历史、全局模式切换、空内容、未完成 TeX、中文组合输入、Tab / Shift+Tab、多行粘贴及 hover / 键盘复制。额外检查普通长公式、宽矩阵及只有 `>` 的引用空行。

`test-display-math-fences` 覆盖 4 个语言别名 × 12 种容器，共 48 组，分配宽窄视口与反引号 / 波浪号围栏。检查共用阅读组件、上源码下结果、灰色复制与全选、输入、缩进、回车、撤销、模式切换、四方向光标进入、错误结果恢复，以及 HTML / PDF / Word 共用渲染入口。可选 `$` / `$$` 包裹只用于解释公式，复制和编辑保留原正文；未闭合围栏保留可编辑源码，普通代码与其他语言不转换。导出入口断言不等同于生成并人工检查完整 PDF / Word 文件。

公式编辑面板追加背景边界和引用竖线的对齐断言，包含列表续段、三层引用、列表内引用、任务列表、Tab 与脚注内引用。另有 22 组窄窗口（320px / 520px）、不同源码字号（12px / 24px）、长公式、文末、空公式和错误内容检查；背景共用 Live 容器边界，源码前缀按源码字体补偿，正文保留普通代码块的内边距。脚注的固定间隔也按 Live 字号计算，避免在源码区与结果区分别使用不同的 `em`。引用前缀可以位于面板外侧；公式正文、结果和操作按钮须留在可用内容范围内。

新增围栏逐帧检查曾抓到输入时的一行偏移：普通代码的即时投影给公式源码临时加入内部行号，改变换行宽度，随后公式刷新又移除。`projectInputCodeBlockLines` 现在让完整 TeX 围栏沿用公式组件的布局归属。`test-display-math-gutter-paint` 同时覆盖原生公式、普通行内代码及公式围栏；`--fences-only` 可独立复现新增场景，观察 DOM 及实际绘制像素，不调用会主动修复测量的 `coordsAtPos`。

## 已复现并修复的问题

1. 脚注 Mermaid 的空行保留了外层 4 个空格；每次输入刷新都会再添加一次，Enter 后光标右移 4 列。源码提取统一使用容器感知的行范围，空行也去掉外层前缀。
2. 预览切到分栏时，外层第二个行号有一帧约 9px 的错位。外层行号先读了内部 gutter 的估算高度；现在先按真实文字行定位。
3. Mermaid 内部首尾方向键无法离开，外层方向键跳过源码区。修复边界交接并保留跨边界选区；公式改为主文档编辑，四向进入 / 离开不经过内部编辑器。
4. 引用内公式新行 / 多行粘贴缺少 `>`，后续输入会使公式消失。公式换行、粘贴和缩进保留容器前缀，也保留用户额外输入的空白。
5. 清空 Mermaid 或暂时缺少 TeX 的 `}` 会让编辑块消失。源码 / 分栏保留空块；独立的 `$$` 闭围栏继续作为结构边界，补完内容可恢复预览。
6. 补空内容兼容时曾与现有空公式兜底重复生成编辑器；这条新增路径已撤去，并保留“每块只能有一个内部编辑器”的回归断言。
7. 文档 Preview 的按钮留白只加在顶部，Mermaid 画布偏下 12px，公式画布偏下 5px；改为上下相等的留白。Mermaid 使用普通代码块的语言标识样式，重绘 SVG 时保留标识。
8. 文档更新时，隐藏的源码位置提示层可能被 morphdom 复用成 Mermaid，后续提示层刷新会隐藏图块。为三种提示层提供固定 DOM key，避免缓存引用指向正文块。
9. 从 Mermaid 源码区点击公式时，旧投影选区释放可能提前替换点击目标。公式在主按钮 pointerdown 时进入主文档源码，避免等待已被移除节点的 click。
10. TeX 行首 `+` 被列表兜底转成圆点，脚注内源码空白被替换成回链占位。公式源码行退出列表、分隔线和脚注空白替换流程，保持原字符。
11. 公式编号不能随普通公式断点任意重排。带编号公式与矩阵等不可拆结构自动适应宽度；不使用横向滚动。

## 结果与限制

本轮追加的公式边界与稳定性检查：

- `test-display-math-stability` 在 Live 字体 16px / Source 字体 14px 下逐帧检查：方向键、输入和删除保持结果 DOM，不出现先缩再长的预览高度；折叠公式遵守绝对、相对、间隔和关闭行号规则。引用内公式 Backspace 只删除输入的字符。
- `test-math-boundary-recovery` 比较共享扫描器和 HTML 渲染：残缺块在标题、代码围栏、容器退出、独立同一行公式之前终止；三连及四连美元符保留为源码；空行和未闭合 TeX 花括号不会破坏已经闭合的公式块。
- 公式编辑区使用轻灰底与分隔线，只有结果区标“预览”；复制、全选位于源码右上角并采用普通代码块的灰色按钮。阅读状态保持透明，Live 全选选中源码；文档 Preview 的块状公式右上角仅保留复制按钮，复制 LaTeX 源码。
- 行内仍采用严格边界：`$x$`、`$2+2$`、`$5$` 可识别；`$ x $` 保留原文，结束符后紧跟数字时不作为行内公式。`$$ x $$` 保留空格兼容。代码与链接的原有排除范围保持。
- `rtk bun run test:source-diff-caret` 覆盖显示修改前内容反复开关、初始 Source / Live 转 Source、公式异常边界、删除行、旧行与当前行换行、新旧文本选区交接和即时点击：535 次当前正文点击与输入通过。原文行是只读比较内容；这些通过记录不能证明照片中的现场故障已经修复。
- Mermaid 退出内部源码区的间歇性跳行已捕获调用栈：外层选区先正确定位，随后原生 DOM focus 暴露旧浏览器选区，DOMObserver 将光标写回第一行。改用 CodeMirror 的 `focus()` 同步原生选区；修复后 709 项交互断言通过，新增四向退出与旧原生选区交接回归也通过。
- Source 空行新增 `test-source-empty-line-caret`：纯空行、只有空格、公式内外及文档末尾，左侧 / 中部 / 右侧点击，初始 Source、Live 转 Source、公式编辑后转 Source，修改前内容开关与实际旧文拖选后返回，共 126 次点击。除文档位置、原生 DOM 选区和输入外，截图像素检查原生光标确实绘制；仍未复现用户现场问题，未修改 Source 点击逻辑。

吸顶时由现有浮动头部完整呈现语言、分界、预览标题、布局动作及四个操作，整行共用不透明图块背景；普通预览与吸顶头部复用同一标题和布局动作创建逻辑。普通标题在吸顶期间保留占位并隐藏，避免出现重复可操作入口。比例继续读取真实预览边界，分隔条仍可从标题行拖动，不新增布局或持久化状态。普通与浮动布局动作之间的键盘焦点随可见入口交接，且不触发页面滚动。

`test-mermaid-visible-controls` 覆盖长源码中段及块末尾的完整标题、不透明背景、五个动作的实际命中、唯一可见布局入口、宽窄比例限制和标题行拖动；键盘上下／左右往返及返回普通标题保留焦点。`test-block-sticky-header-production` 通过实际浮动标题操作布局入口，继续检查普通与浮动按钮位置、复制、缩放、全屏及生命周期。实际 Mermaid 组件视觉冒烟补充中英文、深浅色的块尾吸顶截图，同时保留两种布局及窄窗口外观检查。

本轮快速门禁 71 项全部通过，用时约 31 分钟；类型、架构及测试清单检查通过。吸顶头部、Mermaid 原生编辑及六种长源码容器、控件与焦点、12 组源码外观定向检查通过；实际组件视觉冒烟共核验 13 张布局／语言／主题／窄窗口及块尾吸顶截图。未执行发布验收、全仓库浏览器测试或已安装 VSIX 验证。


## Mermaid 原生编辑测试迁移

浏览器驱动通过主文档位置进入围栏源码，布局动作仍通过实际按钮操作；不再取得块内编辑器或维护第二套行号。历史、保存、IME、字号、相邻列表／表格、容器缩进、文档重载和控件行号身份均沿用各自的行为断言。跨块历史矩阵继续检查真实指针事务的控件替换、移动、安全释放和监听清理。

撤销／重做恢复 Mermaid 时保留原生历史选区；整行插入产生的文本差异可能包含末尾换行，不能用它覆盖原生光标、误定位到结尾围栏。生产浏览器回归同时检查上下／左右布局的准确选区、远处和长源码深处的视口，以及重做后立即输入。

全篇字号和耐久驱动已迁移到主文档源码，普通修复仅运行定向夹具；完整发布或耐久验证仍须按测试流程单独授权。

## 甘特任务文字对比

`test-mermaid-visible-controls` 使用真实 Mermaid 渲染，在深浅色、宽窄 Live 图块中检查甘特任务的实际 SVG 填充色，条内文字对比至少为 4.5:1。`test-mermaid-layout-export` 对 HTML、PDF 和 Word 输出做同样检查，并验证作者指定的任务背景和文字色保持原样。测试同时保留条外标签、日期不重叠和逻辑渲染宽度检查；修复复用既有主题变量，不依赖逐个 SVG 元素覆盖颜色。
