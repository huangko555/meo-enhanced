# 主分支与性能分支整合验收

本轮固定主分支 `7847d543`（0.3.35），整合至性能分支 `bc8ba49a`。两者的共同祖先为 `dc1c68d1`。保留两个父分支的提交历史；整合不修改主分支，不发布扩展。

## 保留的行为与衔接

- 主分支的原生 Mermaid / HTML / 公式编辑、源码格式化、块操作、图片与链接、外观及设置改动继续使用其现有实现。
- 性能分支的 Worker 解析、Live 局部更新与 DOM 复用、长表/Preview 窗口、Source 预算、输入与阅读位置协调、延迟加载提示及独立目录继续保留。
- 新原生编辑的选择和布局状态参与局部失效；滚动请求使用现有统一入口。源码不变的 Mermaid 更新位置元数据时不重新绘图。
- 完整外层 Markdown 解析凭据按不可变文档及解析器身份保存，避免嵌入语言尚未发布时重新扫描或丢失已接受的展示。延迟的局部发布在新输入或选择意图到来后取消。
- 同行代码输入复用行号；表格等价判断继续检查单元格源码范围，避免文字及总长度不变的空格调整留下旧坐标。高度缓存和已挂载 DOM 的所有权不变。

## 同环境首开对照

三个版本在同一时段顺序复测，期间不并行运行其他浏览器验收。每个版本运行相同的中立控制器、四份合成文档、三种直接打开模式，每种组合两轮，共 72 例。控制器不覆盖生产策略；每份源码使用自身锁定依赖。CodeMirror 公共 `EditorView.findFromDOM` 用于跨版本操作。所有例均检查异常、实际光标及首个数字到达预期源码位置。

## 验证与边界

最后一轮完整门禁执行了全部 401 条命令，其中 398 条通过、3 条失败，原始报告保存在 `.local/main-integration-acceptance/release-before-final-repair/`。收尾只修复加载退场的跨窗口焦点条件，并校正两项测试前提：真实部分树与异步预备完整树分开检查；公式控件先由可见父块显露，再接受真实鼠标悬停。全部失败项均重新运行。

最终树执行 Quick 计划的全部常规命令，并补充焦点、加载、模式准备、真实语法矩阵、基础编辑能力及打包内容检查，均通过。记录及每条命令日志在 `.local/main-integration-acceptance/final-scoped-validation.json` 和 `logs/`；验证前后暂存树一致。此前完整门禁属于收尾修复前的候选，不把它改写为最终树的全量通过，也没有再执行一轮 release 门禁。类型、构建、暂存架构、清单和提交前隐私检查另行完成。

其他本地证据包括渲染源码专项组合与大文档独立检查，覆盖 Live/Source/Preview 延迟加载、目录冷启动、分栏编辑位置所有权、Preview 表格源身份、长表行窗口和 Worker 历史。这里只执行本地检查，不包含发布或推送。

定向回归还覆盖：4 倍 CPU 节流下另存为的首个实际正文帧与最终位置；冷启动加载中途切换模式；代码围栏回车 12 例；复杂 HTML、原生表格、公式和脚注容器的点击与输入；Preview 字体与预设变化中的同一文字位置；待提交输入与延迟诊断同任务竞争；以及 145 次合成画面的未改动内容稳定性采样。测试按实际可交互的表面取样，加载遮罩下的内部 DOM 不作为已显示正文。

本轮主要兼容修复包括 HTML 缓存依赖折叠状态、代码行尾控件的新行归属、嵌套表格的物理前缀与单元格范围、复用原生单元格的选择所有权、HTML 明确图片尺寸与预留固有尺寸的协调、预览外观变化的文字锚点，以及加载遮罩和首次位置恢复的交接。截图复核覆盖明暗主题的 HTML 与折叠代码/图表。

后续回归确认两处定位交接缺口：冷启动尚无外层编辑器时，Preview 分块测量需由自身保留真实文字位置；原生表格的新鼠标按下需在主编辑器状态更新之前释放旧单元格的定位锁。对应回归分别检查相邻块延迟期间连续 12 帧的目的段落可见性，以及鼠标按下瞬间不超过 0.5px 的位移。移除表格修复的隔离对照复现了 31px 拉回；有修复时通过。Preview 同时覆盖没有外层回调和外层尚未就绪而拒绝接管两条路径。

加载退场的焦点修复通过暂停真实展示帧复现：用户已打开 Workbench 菜单，旧实现仍会从内部 body 恢复到编辑器。新增当前文档焦点条件后，Live 与 Source 都保留外部菜单；用户真正返回内容窗口时，原位置和首个输入继续有效。原有工具栏全套检查和实际光标绘制证据保留。

语法矩阵现在把真实解析限制在可见的 3000 字符前缀，稳定验证部分树回退、可见富内容、选择、历史和 8ms 刷新；再运行生产异步准备入口，验证准备期间保留 Source、完整树包含离屏表格、安装 Live 不重复解析。此前按墙钟快慢碰巧得到完整树的前提已移除。公式提示的诊断则确认第一次指针事件落在正文；夹具先悬停公式显露控件后，实际事件直接命中复制按钮，原提示语义和时序断言保留，未修改工具提示生产机制。

中间门禁有一次 Preview 链接激活超时，独立完整诊断、保持原点击时序的诊断及 144 组尺寸/缩放切换的 288 次真实激活均未复现。原有消息和键盘/鼠标语义断言保留，只增强失败动作及布局上下文记录；不把尚未证实的根因描述为已修复。后续完整门禁中的同一链接检查通过，原始失败与中断记录一并保留。

测试使用仓库合同及隔离无头浏览器，Host 渲染在 Bun 进程中运行。没有操作 Codex Test VM，也没有把本轮检查描述为 VS Code 原生窗口、真实输入法候选窗口或 Win32 滚动条验收。
