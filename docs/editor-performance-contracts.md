# 编辑体验与性能接入约束

本文是后续功能开发的维护约束。[性能工作记录](large-document-performance.md)和[策略证据](large-document-policy-evidence.md)用于查阅原因与历史测量；具体阈值、接口和测试命令以当前源码及 `package.json` 为准。

## 改动前确定影响

按行为判断是否需要接入性能机制，包括输入、渲染、布局、滚动、焦点、历史、模式切换、异步资源及相关设置。按钮、弹窗、样式和新语法也可能影响这些行为。实现前找出受影响的状态所有者、同步热路径与派生更新路径；无需等待用户单独提出“性能优化”。纯文案等未改变这些行为的改动沿用普通验证流程。

## 接入现有机制

| 影响范围 | 首先查阅的现有入口 | 维护要求 |
| --- | --- | --- |
| 正文／HTML 语义和样式 | [内容规则与样式管理](content-policy.md)、`src/shared/markdownContentRules.ts`、`src/shared/markdownContentStyles.ts` | 共用语义与基础样式，按表面适配呈现；语法适配同时接入普通与后台路径，外观调整只投影 CSS。 |
| 输入与派生工作 | [liveInputDerivedWork.ts](../webview/src/editor/liveInputDerivedWork.ts)、[liveMode.ts](../webview/src/liveMode.ts) | 立即接受文本和选择变化；昂贵派生工作合并调度。键入、IME、粘贴、工具栏、颜色调整及历史操作均保留正确的事务来源，接入对应的更新路径。 |
| Live 局部呈现 | [liveMode.ts](../webview/src/liveMode.ts)、[liveWidgetPositions.ts](../webview/src/editor/liveWidgetPositions.ts) | 映射未变范围，复用仍然有效的装饰和 DOM。能证明局部影响时只更新受影响内容；引用、语法边界或其他全局依赖变化时走正确的失效与重建路径。 |
| 语法与全文功能 | [backgroundMarkdownStructure.ts](../webview/src/editor/backgroundMarkdownStructure.ts)、[markdownStructure.ts](../webview/src/editor/markdownStructure.ts) | 接受与当前文档版本匹配的结果，明确区分部分树与完整结果。目录、搜索和引用依据完整文本模型，独立于是否挂载屏外 DOM。 |
| 阅读位置与分栏同步 | [viewportController.ts](../webview/src/helpers/viewportController.ts)、[interactionContinuity.ts](../webview/src/editor/interactionContinuity.ts) | 通过现有控制器交接定位所有权；新的用户操作使旧的定位任务失效。输入、资源完成与模式切换遵守同一位置规则。 |
| 块编辑与浮层焦点 | [blockInteraction.ts](../webview/src/editor/blockInteraction.ts)、[livePointerSelection.ts](../webview/src/editor/livePointerSelection.ts) | 按下、拖动、松开及取消构成完整交互；按住鼠标期间保持被操作内容稳定。工具栏与弹窗借用焦点后恢复有效选择，区分操作控件和新的正文选择。 |
| 表格操作 | [tableCommand.ts](../webview/src/application/tableCommand.ts)、[codeMirrorTableCommandEffectAdapter.ts](../webview/src/editor/internal/codeMirrorTableCommandEffectAdapter.ts) | 待提交单元格输入与结构命令使用现有事务及历史所有者；移动、排序、删除后保持有效焦点、源码位置和撤销重做。 |
| Preview 与屏外资源 | [preview.ts](../webview/src/helpers/preview.ts)、[previewReadingWork.ts](../webview/src/application/previewReadingWork.ts)、[previewViewport.ts](../webview/src/helpers/previewViewport.ts)、[previewViewportResources.ts](../webview/src/helpers/previewViewportResources.ts) | 保留已接受的正文，复用有效节点，以当前窗口调度资源与测量；异步完成校验当前版本和生命周期，隐藏或销毁时释放相应工作。 |
| 大文档策略 | [largeDocument.ts](../src/foundation/largeDocument.ts)、[策略证据](large-document-policy-evidence.md) | 打开方式偏好与运行时优化分别处理。普通文档保留轻量路径，同时覆盖小而复杂、巨型单块和编辑后增长的文档。 |

功能优先接入上述所有者；确需替换时，连同取消、失败、历史和销毁语义一起迁移，并移除被替代路径。每项文档状态保持一个权威来源，缓存和展示投影可从它重建。新建缓存、Worker 或调度层应对应已测出的缺口，并定义失效条件、容量和生命周期。

## 元素的更新单位

更新单位由操作及语义依赖共同决定，不给每种元素规定一个固定大小。区分立即接受的文本变化、需要重算的语义范围和真正需要写入的 DOM；重算一个块不等于替换它的所有节点。未改范围通过位置映射保留，控件通过相等比较或局部 DOM 更新复用。

映射后的过滤和新增也必须通过 `liveWidgetPositions.ts` 保留装饰分层及共享片段。直接修改已合并的装饰集合，可能让高度比较漏掉仍然存在的块；后台等待阶段同样遵守这条约束。

| 元素与操作 | 首选更新范围 | 必须扩大的情况 |
| --- | --- | --- |
| 正文、行内格式 | 变更文本及所属段落；未改装饰映射保留 | 行内分隔符、段落边界或容器归属改变 |
| 标题 | 标题行；Setext 标题包含下划线行；对应目录条目 | 标题类型或层级改变后，更新依赖它的目录层级与折叠范围 |
| 列表、任务 | 勾选仅更新任务控件状态；正文编辑更新条目内的段落 | 标记、缩进、换行或结构命令影响列表子树；相邻列表可能合并时包含其编号和松紧关系 |
| 表格 | 单元格输入更新该格；源码位移仅映射保留控件的操作坐标；行命令更新该表的行结构；列命令更新列结构及该表布局 | 单元格诊断与脚注编号变化更新其依赖预览；列数、对齐、内容度量或容器宽度改变时重算相关列宽；新挂载表格在首次绘制前接受列宽，未改表格不因挂载事件重投影 |
| 代码块、公式、HTML、Mermaid | 输入立即映射现有呈现；新字符在权威 token 到达前继承有效的相邻 token 样式；派生更新由所属块接收 | 分隔符、语言、容器或源/结果模式改变时扩大到完整块；围栏未闭合时允许影响后续语法 |
| 链接、图片、脚注 | 编辑处的文字或控件；异步图片完成只更新对应资源与必要几何 | 引用定义、标签身份或脚注编号改变时，失效所有实际依赖者，不能只检查可见区域 |
| 主题、字体、窗口大小 | 对应的配色、度量或可见布局消费者 | 主题可以影响全部可见 token；字体和宽度可以影响换行、块高度及阅读锚点，仍不改变文档语义 |

局部路径必须说明边界为何封闭、依赖为何未变，以及何时交回完整解析。不能证明时保留可用的已接受呈现，让既有后台工作验证新版本，避免把部分树或占位树当作完整结果发布。局部同步解析也必须有容量上限；超大单块继续使用后台路径。不得为每类元素另建调度器或一份可独立修改的文档状态。

列表前缀、编辑动作、选择与历史的共同规则及对应合同见[列表编辑规则](list-editing.md)。
行内识别与连续段归一化消费共同前缀，布局、指针、原生历史和后台派生工作继续由上述入口拥有。

正在编辑的 Mermaid、HTML 和公式结果通过输入所有者的帧检查点更新，不等待全文派生工作的静默窗口。检查点只读取当前版本，沿用已有 Widget 索引、编辑范围及渲染器；源块超过局部容量时交回原路径，不把局部结果标记为全文已就绪。Mermaid 只在已知闭合围栏内进行局部源码读取，保留容器前缀和制表位；无法证明边界或保真的输入交回原解析。连续输入合并到固定的下一检查点，IME、模式切换、外部替换和销毁沿用同一生命周期取消。Mermaid 额外合并连续布局请求，规范的静默刷新仍可立即接受最新源码。

这些约束沿用 [CodeMirror 的装饰映射与 Widget DOM 复用](https://codemirror.net/docs/ref/#view.WidgetType) 和 [Lezer 的语法片段复用](https://lezer.codemirror.net/docs/guide/#incremental-parsing)。语法边界变化可能扩大解析范围，因此以可证明的依赖范围为准，不承诺每次只更新一个字符或一个 DOM 节点。回归同时检查中间帧、未改节点身份、最终语义和工作量预算。

## 用户可见的稳定性

- 菜单栏属于固定窗口外壳。首屏内联样式与运行时样式都保持外壳贴合窗口且不可滚动；正文增长、定位、焦点恢复、搜索、模式切换与浮层操作不得移动菜单栏。窗口变化只调整可用尺寸与既有溢出菜单，文档滚动仍由各自视口拥有。Preview 元素定位通过 `previewDocumentReveal.ts` 显露文档及其内部滚动容器，不让原生 `scrollIntoView` 穿过 iframe 滚动工作台的 Webview 容器；显式焦点交接使用 `preventScroll`。相关改动保留逐帧几何检查，并核对原生宿主的外层容器，不能仅靠编辑器内部的 `top: 0`、最终截图或个别事件拦截证明稳定。
- 输入期间保留未变内容的身份、行号和几何；内容自身换行或结构变化带来的布局变化属于正常行为。需要重新解析时保留有效呈现，避免让未完成结果反复替换正文。
- Mermaid 前方的编辑只改变图块坐标时，复用同一块相机对应的原图与尺寸观察，仅更新外壳行号和操作目标；图内容、呈现上下文或块身份变化才交回对应更新。相同图源码不能单独作为跨块复用依据。
- 扩展图块沿用主编辑器的块身份保存临时相机：用户调整的缩放与画布中心内容坐标跨源码刷新、上下／左右布局保留，不写入 Markdown 或持久化观看状态，不串到其他块或全屏。未调整的内嵌图仍按内容与容器自动适应；“重置”恢复自动适应。Preview 图块外壳由主编辑器统一，默认预设使用代码块底色，其他预设默认透明并允许预设自身覆盖；扩展不额外铺底色。
- 普通文本选区跨过列表时保留圆点、编号和任务控件；只有光标进入标记内部或精确选择标记本身时揭示源码。复制、替换和历史仍依据主文档的原始范围。Markdown 回车延续当前行已有缩进，不调用内嵌语言的括号／标签增缩进；块所属容器前缀由既有块输入所有者保留，不能借换行触发全文解析或重建。
- Live 鼠标勾选任务时，光标已在该任务正文内则保留编辑位置，否则在同一次更新中移到标记及分隔空白后的正文起点；维持实际阅读视口，不追踪屏外旧光标。键盘勾选保留原生控件焦点。勾选和列表正文起点退格的语义位置随原生历史保存，撤销／重做在一次视图提交中接受有效选择，不先揭示标记或定位到最后一个子项；原生正文历史输入与快捷键共用历史所有者。子项提升缩进时映射保留未改任务标记，后台解析继续拥有最终结构。
- 历史接受文本时同时接受有效交互位置。通用正文历史保留原生历史的完整定向选区及主选区；列表和表格的语义位置随同一历史事件保存，结构命令记录操作前后的单元格身份和原生选择。焦点恢复不能用单个变更位置覆盖原生选区。恢复不得先发布无关正文光标，再等派生呈现纠正。沿用既有历史、表格焦点和视口所有者，迟到恢复受新的输入与导航取消，不另建文档副本或独立撤销栈。各项编辑按[统一历史验收合同](testing-workflow.md#shared-undoredo-acceptance)检查双向恢复及中间帧。
- 显式格式化的前后完整选区随同一原生历史事件保存；光标处于未改后缀或尾部空白时，最小文本差异不能取代该有效位置。格式化与搜索复用历史选区适配器，只有显式搜索目标接管搜索定位语义，普通输入不增加格式化元数据或全文工作。
- 已确认块内的回车可为紧接着的回车保留一次延续信息，避免 Worker 等待期间丢失容器。信息以输出文档的弱引用身份及精确光标位置验证，另一笔编辑或其他位置不能使用，不持有文档、历史或编辑器，也不发布为语法结果。
- 冷 Source 的首次容器代码输入若尚无完整语法，可从文档起点至当前行做最多 4096 字符的命令内语法判断；起点保证前文上下文完整，仍由原有 Markdown 语法解析。超过上限继续使用已有结果及后台路径；局部前缀不发布为全局语法，不等待 Worker，也不扫描全文。
- 光标仍可见时维持当前阅读位置；确需显露光标或命令目标时采用最小滚动。新的点击、键盘导航和用户滚动优先于旧的异步定位任务。验收同时观察输入中及输入停止后的收敛过程。
- 同一主动定位意图只选择一种放置策略：普通输入采用最近边及必要安全距离；历史离屏目标保留上下文；搜索及显式跳转沿用各自居中或靠上语义。原生自动显露按实际请求的消费或替换交接给定位所有者，不按微任务期限放行第二次滚动。最终位置与对应虚拟视口内容在绘制前一起接受，不能只挂载光标行、等待下一帧补正文；真实几何变化仍由既有布局校正吸收。
- 表格的新指针操作从按下至松开拥有选点及拖选范围；窗口激活迟到恢复的旧输入或正文焦点不能重显旧单元格外框、清除该范围或使光标落到表格外。松开后保留已确认单元格的返回目标或多格选区，直到新的正文点击、键盘、导航、离开编辑器、失焦或销毁接管；先处理 focusout，不能让旧恢复提前结束单元格编辑。表格编辑器和控件共享 `tablePointerTarget` 的文字、边线、列宽与操作控件命中规则；原生 textarea 延伸到折叠边框的像素不能当作文字落点。文字落点确认后才更新编辑返回目标；边线单击保持原正文或原单元格的光标与选区，列宽拖动只改变布局。原单元格内的原生文字点击仍由输入控件处理；没有新指针操作的窗口返回保留原选区。沿用表格选择所有者投影当前范围，不扫描全文或重建未改表格。
- 原生激活可能在同一次按下与松开之间再次失焦、回焦。该过程释放正文的呈现冻结，但保留尚未结束的表格指针焦点目标；匹配的松开、取消、丢失捕获或新的输入负责结束。激活外框反馈在该次松开后显现，不能按下后就提前结束绘制保护；屏外松开后首次无按键指针移动同样结束保护。
- `editorFocusController` 统一区分正文选点、可输入控件、借用焦点的界面与显式交接。工具栏空白等借用焦点的点击不改变编辑返回目标，和正文点击一样等待完整激活手势后结束绘制保护。中间正文焦点不能在 focusout 阶段结束原生单元格；恢复仍调用编辑器所拥有的有效返回目标，不另存正文选区。新的正文点击、键盘输入、可输入控件和命令接管时结束借用，不能阻挡 Tab、搜索、模式切换或其他命令的新目标。
- 首次编辑器在加载遮罩下未能取得焦点时，保留一次性初始意图；仅在实际返回 Webview、编辑区域已连接且可见并可交互时兑现，不抢工作台菜单、输入框或模态的焦点。挂载前后的新交互都能取消旧意图，首次聚焦后不再排队恢复；回焦保留当前阅读视口，后续控件接管后迟到通知不得重开正文焦点。
- 宿主窗口活跃状态由 VS Code 的 `WindowState.focused` 经统一 Protocol 投影；它只决定焦点反馈，不授予键盘焦点。Webview 在同一宿主内的短暂失焦不能撤销已接受的编辑反馈，也不能重启一段可见的隐藏／显示过程。真正离开宿主窗口仍隐藏编辑单元格外框；下一次激活先完成选点交接，再显现有效目标。失焦期间允许滚动到远处，回焦与迟到的 Host 通知不得把已开始的表格手势交回旧正文选区。沿用现有焦点、表格选择和视口所有者，只投影必要类名，不新增轮询或全文工作。
- Source/Live 的侧边预览遵守现有同步开关及定位所有权：关闭同步时维持右侧阅读锚点；开启时通过源码与渲染几何的映射同步。点击后的最小显露应平滑交接给下一次滚动；程序滚动不能形成反向反馈。
- Source 定位底色属于预览控制器，正文增量提交保留同一节点及已接受的位置，直到新映射就绪后同步更新。已知图片尺寸等同步布局输入先恢复，再接受定位几何；屏外图片仍遵守该顺序，输入中间帧的底色须与对应正文对齐。新映射确认目标没有对应内容、没有可见高度或尚处于窗口占位区域时隐藏底色；空白字符本身不决定显隐，代码块内有实际渲染位置的空行仍可定位。切换位置、关闭侧边预览及进入完整 Preview 继续由既有显隐所有者处理。
- 侧边定位优先使用当前源码行的实际文字或代码行，列表项不包含无关子列表，脚注标准化保留子块的原始行身份；公式与图表仍按完整结果定位。文字范围在接受 DOM 时建立，查询沿用现有几何索引，不在光标热路径遍历全文。透明定位层须在代码等块背景上可见，并保留原有文字选择、链接与控件交互；没有独立渲染结果的表格分隔行、隐藏注释等不继承任意外层范围。Source 定位注意力仍有效且目标可见时，资源重排沿用视口事务保留该行文字见证，避免上方图表变高后把目标推到屏外；内容编辑和新的阅读手势继续按原有意图接管。
- Source 键盘导航与点击共用侧边预览的最小显露入口；目标可见时不滚动，关闭同步时维持独立阅读。键入、历史和程序化选择不冒充键盘导航。普通代码围栏的开头／结尾分别定位块顶部／底部的一行区域，未闭合围栏不生成结尾身份；代码正文、缩进代码及图表公式保留各自定位语义。
- 脚注位置按表面固定：侧边预览在源码定义处显示，完整 Preview 与导出集中到文末，不增加位置设置。编号、引用和返回链接保持一致。侧边脚注按普通源码块参与连续同步，不维护异位脚注对照或键盘跨出交接状态；滚动热路径复用既有几何索引。相邻定义使用脚注列表间距，同一定义内的段落间隔保持正常。
- 模式切换保持当前实际阅读的同一内容：中间定义映射到完整 Preview 的对应文末脚注，正文及引用标号仍映射到正文，反向切换回同一源码位置。旧光标不覆盖新的阅读锚点。普通与窗口化预览遵守同一规则；呈现身份包含侧边／完整布局，同文本的不同布局不能复用旧结果或几何，迟到结果继续受现有代次和生命周期校验。隐藏不改变呈现布局；相同文本、布局和渲染环境可复用已接受结果，取消其他布局的在途请求不使它失效。真实设置、资源和可访问性变化仍立即失效缓存。
- Live、Source、Preview 及分栏之间保留文本、有效选择和语义阅读位置。虚拟化只改变呈现范围，保存、复制、查找、导出和历史仍使用完整文档。
- HTML 阅读文字由原生阅读区域拥有焦点及 DOM 选区，编辑器刷新期间保留正在增长的选区，复制使用所选渲染文字。阅读区域阻止原生输入改写呈现，单击松开后交回主文档源码编辑；正文编辑中的派生结果继续排除在源码选区之外。公式结果与属性数组标签保持静态，完成单击后进入源码，超过移动阈值、折返拖动及取消均不激活。各入口释放自身的指针监听，保留链接、折叠及原生 HTML 控件的阅读操作。
- Preview 连续比较预设、字体或排版时沿用同一阅读字符，直到新的阅读交互、外部定位、内容变化或隐藏结束保留。渲染器更换文字节点时，只在同一源码范围内重新绑定无歧义的原文字。窗口在最终预设样式下建立高度映射；公式的异步自适应测量也经过既有视口事务。Preview 主导阅读时，外观调整后的两侧位置作为已接受的一对，不把布局补偿重新投影成 Source 滚动；下一次真实手势从新位置继续。Source 主导的冷窗口加载或资源更新继续投影源码目标。
- 隐藏视图可以推迟渲染，不能漏接设置变化。字号（含自动／自定义切换）、行间距等渲染输入改变时，通过既有 Preview 生命周期所有者立即使缓存及在途旧结果失效；重新显示的首个有效呈现使用最新设置。同文本文档不能单独证明缓存有效；无变化的模式切换继续复用缓存，不以每次强制重渲染兜底。相关回归覆盖完整与侧边 Preview、普通与窗口化文档，以及预加载或渲染结果迟到的情况。
- 模式切换等待期间，有已接受的旧内容时保留正文并延迟 200ms 显示加载提示；目标区域没有可读内容时，从区域出现的首帧立即提示，不先展示无反馈底色。首次打开的静态外壳同样提供反馈，并持续交接给运行时。内容就绪立即显示，不强制加载动画停留。目录保留其局部延迟，高频编辑更新保留正文；慢更新的修复优先针对调度和呈现，避免为每次输入增加加载提示。

## 按风险验证并完成交付

测试层级、长验收授权与证据复用统一遵循[测试流程](testing-workflow.md#validation-for-commits-and-merges)。普通提交、合并和功能完成本身不触发发布级长验收；文档修改验证链接及相关文档合同，复用仍然覆盖当前运行时代码的证据。

按本次改动影响选择下列场景，涉及共享基础机制时扩大覆盖面：

规模配对、优化路径证明及完成条件按[文档规模覆盖](testing-workflow.md#document-scale-coverage)执行。核心 quick 只提供基础反馈；受影响功能仍须验证相应长文档路径。

- **规模与模式：**小而简单、小而复杂、大文档、巨型单块；相关模式的冷启动、暖缓存切换，以及单栏与侧边预览。
- **真实交互：**点击、按住与松开、连续输入、IME、换行、粘贴、相关工具栏及浮层、撤销重做、滚轮与滚动条。表格、代码、公式、HTML、Mermaid、脚注等按依赖关系取样。
- **中间状态：**输入当帧、派生更新、输入停止后、Worker/图片/字体迟到、模式切换取消及销毁。闪烁或跳动回归检查中间帧与最终状态，单张结束截图不足以证明稳定。
- **正确性与成本：**核对文本、格式、选择、历史及阅读位置；性能检查优先约束扫描、DOM 与资源工作的规模。耗时对照固定文档、环境和构建，区分冷暖并保留多次结果；单次无头浏览器测量不表述为原生 VS Code 或所有设备上的保证。

修复优先扩展现有行为回归，验证用户可见结果与必要的工作预算。新增或移动测试按[测试登记流程](testing-workflow.md#adding-or-changing-tests)接入门禁；简单文案无需增加复述实现的测试。

完成时应能说明：受影响行为由哪个机制承接、相关回归结果、复用证据的适用范围，以及尚未执行的必要验收。发布前在候选冻结后安排完整发布门禁、长时交互和适用的原生安装验收；后续运行时代码变化重新判断受影响证据。
