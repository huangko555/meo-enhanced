# 行号、光标与布局稳定性契约

范围是生产编辑器的正文、源码行、渲染块、嵌套编辑区与只读修改前内容。
行号格式使用 `sourceLineNumbers.ts`；外层位置由 CodeMirror 的文档布局决定。
Mermaid 内部编辑器和 HTML 语义行需要源码映射，投射位置取自当前可见内容的真实几何。

## 不变量

1. 没有实际换行、内容高度或滚动变化时，正文与对应行号不得发生可见的移动、隐藏或闪烁。
   编号规则未变的源码行复用既有节点；相对编号随光标移动更新文字，不改变位置。
2. 发生高度变化时，行号与正文在同一次可见更新中对齐，误差不超过 1 CSS px；
   不允许先显示估算位置、下一帧再恢复。已测高度仅在同一编辑器、相同布局身份间复用。
3. 绝对、相对、间隔、关闭规则同时适用于正文与渲染块的文档行号；块内局部行号保持自己的语义。
4. 原生选区、源码偏移和输入位置一致。空行、只含空格的行与文档末尾可点击，
   光标不得被行号栏、预览或只读旧内容遮住。
5. 每个挂载的投射只有一个更新与释放入口。几何读取与 DOM 写入分开，重复触发合并；
   测量收敛后停止调度，销毁编辑器或切换布局后释放观察器与待执行任务。

## 验证接口

测试通过生产 `createEditor`、公开模式/设置/基线操作及浏览器真实输入驱动。
连续输入的观察只读取模型位置与 DOM 矩形，禁止调用会主动刷新布局的 `coordsAtPos`。
观察帧须包含输入期间的中间状态；最终对齐不代表瞬时稳定。
关键光标与绘制用例同时检查截图像素，输入法事件测试与 Windows 候选窗现场验证分别记录。

## 回归入口

- 快速门禁：普通正文换行、无换行、渲染块与输入节奏的被动检查。
- 专项门禁：公式、Mermaid、HTML、行号设置、模式/焦点切换、字体与缩放、比较内容。
- 真实实例复核：保留当前未保存文档，在同一隔离 VS Code 中加载构建并验证交互。

每个新增用例先确认能检测已知错误，再收敛相关实现。有限的用例集合不等于所有文档均已覆盖。

`layoutMeasurement.ts` 集中封装当前固定版本 CodeMirror 6.43.15 的同步测量与原生选区刷新依赖。
常规投射使用 `requestMeasure` 的读写阶段；挂载或尺寸观察在下一次绘制前合并完成测量。
纯装饰更新若改变了本来与模型一致的浏览器选区，主编辑器在同一次更新中刷新缓存并恢复选区；
已有待处理选区、组合输入、嵌入控件焦点和模式重配均不进入该路径。
升级 CodeMirror 时必须运行以上布局、原生光标与实际绘制检查，不能只依赖类型检查。

## 本次验收（2026-10-10）

- 编号契约：Mermaid / HTML 的全部编号模式、相对编号随光标更新、分栏第一帧、
  字体与宽度变化、连续输入、节点复用、空闲停止 DOM 写入与销毁后无异常通过。
- 连续输入：7 组场景通过；一次快速门禁记录 1,675 个被动 DOM 帧、78 个实际绘制像素帧。
  输入包括约 30ms 的按键重复、删除和浏览器组合输入，含 120% / 150% 比较视图。
- 光标：126 次空行点击与输入检查；2,112 行文档的 6 个分散目标、旧内容开关与
  150% 缩放，共 60 次实际光标截图检查通过。
- Mermaid 709 项相关交互、HTML 内容及模式选区连续性检查通过。
- 快速门禁完成 34 项，其中 3 项最初失败于旧公式模式按钮。
  斜杠菜单、设置返回焦点、工具栏返回焦点测试已迁移为当前公式主文档编辑路径，分别复跑通过。
  其余 31 项通过。未重新跑全套发布或全量长文档扫描。
