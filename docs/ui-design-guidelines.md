# 界面设计约定

这份约定记录已经确认的 MEO Enhanced 界面取向。设计新控件或调整现有控件时，先查看正在使用的组件和主题变量，再按这些规则处理；用户在具体任务中的新要求优先。

## 视觉与主题

- 以现有界面的圆角矩形作为主要形状。分段控件、菜单、对话框按钮保持同一套圆角和边距语言。开关保留目前的胶囊形状与切换动画，作为少量有功能辨识度的例外。
- 参考图用于提取明暗层级、选中关系和对比度，不直接复制其色值或尺寸。颜色跟随界面主题，浅色与深色都要检查。
- 未选中的分段选项文字可以弱一些；悬停时只增强文字颜色，不增加悬停底色。键盘聚焦还应有可见的焦点标识。浅色模式要能清楚分辨普通与悬停状态，深色模式保持现有强度。
- 工具栏单色图标继承文字颜色。具有格式含义的 HTML、PDF、Word 图标保留各自原色；图标内的透明镂空为白色，轮廓外透明。

## 控件与排版

- 所有分段控件由 `webview/src/adapters/segmentedControl.ts` 创建，开关使用 `webview/src/adapters/menuSwitch.ts`；共同样式集中在 `webview/src/styles.css`。调整共享外观时先改共同来源，再检查特殊尺寸的使用处。
- 分段控件选项之间不留人为间隙，同一控件的选项等宽。选中块四边保持相同的紧凑内距；文字不能贴边。切换时文字位置固定，选中块只横向平移，宽高和圆角不变；减少动画设置下直接切换。
- 分段控件默认按内容自适应宽度；需要稳定对齐时指定总宽并平均分配选项。右上角模式切换在中英文之间保持同宽。短文案优先，例如“开 / 关”。
- 布局优先紧凑，但不能靠裁切标签换取宽度。中文和英文标签都保持单行；图标、文字、控件的左边界与右边界要有规律地对齐。行高按内容决定，只有开关的行无需沿用分段控件行高。
- 按钮宽度随文字变化，高度、文字内边距和圆角参照调色弹窗中的“取消 / 应用”。同一横幅里的强调、普通、关闭按钮尺寸协调；强调按钮用反色，普通按钮用中性边框，关闭按钮保持低强调。

## 说明气泡

- 共用气泡使用 `webview/src/styles.css` 的 `.meo-tooltip`：10px 圆角，浅色主题背景固定 `#0d0d0d`，深色主题背景固定 `#1a1a1a`，文字统一 `#f5f5f5`，两种主题均使用局部灰度渲染消除文字彩边，无描边、无外阴影。下方带箭头的气泡加 `.meo-tooltip--arrow`，箭头复用气泡底色并沿气泡中线对齐。
- 按钮的小气泡保持单行、按内容决定宽度，按钮、箭头和气泡中心对齐；悬停立即显示，键盘聚焦使用同一提示。使用处负责定位和触发，表面样式复用共同来源。较长说明的宽度和换行按场景处理；自定义气泡使用 `aria-describedby` 关联，并替代浏览器原生 `title` 提示。

## 设置与工具栏

- 设置按“文档显示 / 打开文档时 / 界面设置”等清楚的功能组组织。标题应直接说明结果，英文也用常见短语，避免抽象缩写。设置行采用左侧图标和单行标签、右侧控件的结构。
- 设置菜单维持紧凑宽度，同时完整显示英文标签。分段控件与字号步进器的左右边缘对齐；分隔线维持菜单内部的短线样式。
- 普通选项不加无意义的悬停提示。确实需要解释的选项，在标签旁放信息图标，悬停图标才显示提示；提示层要盖过相邻行和控件。点选设置值后菜单保持打开，以便连续调整。
- 预览工具栏顺序为“预览字体 → 预览主题 → 代码着色 → HTML 注释”。注释选项使用“显示 / 隐藏”，英文为“HTML comments · Show / Hide”；新用户默认隐藏。
- 导出入口使用“导出为...”与随主题变色的导出图标。菜单包含 HTML、PDF、Word 各自的普通版和含目录版，沿按钮左边缘展开，表面颜色沿用表格按钮的悬停菜单。鼠标悬停时显示菜单，离开按钮和菜单区域后关闭，点击入口不应使菜单常驻。
- 预览字体的选择框及其弹出菜单使用与导出菜单相同的主题表面颜色，避免单独偏蓝的底色。
- “变更”菜单中的选项不使用整行悬停提示；若确有无法从标签表达的必要说明，应在标签旁放信息图标，并仅在悬停图标时显示。

## 交付检查

检查中文和英文、浅色和深色，以及普通、悬停、选中、键盘聚焦状态。确认文字不换行或裁切，切换时文字不移动，菜单和提示不被遮挡。小幅纯样式调整先用开发模式实时预览；一组连贯改动完成后按 `docs/testing-workflow.md` 运行相应检查。

## 完整设置窗口

- 小菜单维持 288px，六项文档显示开关及原有主题、语言、字号控件；通过“更多设置”进入完整窗口。
- 完整窗口使用“常规 / 输入 / 快捷键”三个 Tab、左侧章节导航和连续滚动正文。搜索框与“设置”标题同排，按窗口中线居中；两侧保留标题和关闭按钮的位置，窄屏收缩搜索宽度。标题行与 Tab 行保持紧凑间距。窗口标题保持简洁，Tab 独占下一行并使用统一字号和常规字重，以选中颜色和下划线突出当前分类。说明保持简短，二选多选优先展开单选选项，避免下拉菜单。
- 章节标题可放大加粗；侧栏选中使用中性色。Tab 使用强调色，标签下划线贴住分隔线且不覆盖数量徽标。搜索图标始终可见，非空输入显示中性清除按钮；聚焦只改变一像素边框颜色。
- 小菜单开关保留整行交互。完整窗口开关只点击控件本体，正文行不加悬停底色；单选本体与标签有一致的小手光标。主题、语言、字号只有右侧控件可交互。
- 只有快捷键 Tab 有底部恢复默认动作，确认浮层不改变窗口尺寸。冲突替换使用既有红色文字，必须明确点击；恢复默认保留其他设置。
- 普通设置行保持紧凑，大分类之间增加间距并用分隔线收尾。完整窗口的主题、语言、字号控件同高、右侧对齐；自动字号下整个步进器禁用，保留上次自定义值。
- 设置动作按钮统一高度和内边距，宽度按文案变化；小菜单的“更多设置”保留适中的独立尺寸，小菜单宽度不变。搜索框复用主题输入框的完整配色和不透明底色，避免单独灰阶处理与窗口背景产生偏色观感。
- 搜索同时匹配每项设置的中英文名称、说明、选项值和常用同义词，不受界面语言影响。多个词须在同一项中全部匹配；快捷键按当前实际绑定检索。输入时保留搜索框焦点，三个 Tab 的结果数量使用同一套匹配规则。
- 设置项的搜索词按稳定 ID 集中维护在 `webview/src/application/settingsCatalog.ts`。新增、删除、重命名或修改设置项时，同步维护对应的中英文词条，覆盖常用叫法、功能结果和关联术语，并核对名称、说明、选项值及当前快捷键都进入索引。完成前确认设置与命令清单的关键词覆盖完整，并在两种界面语言下验证名称、代表性别名及结果数量一致。
- 搜索清除和窗口关闭使用 SVG 图标及方形点击区域，清除按钮与搜索框垂直居中，关闭按钮与搜索框中线对齐；图标在按钮内部水平、垂直居中。
- 从文档打开完整设置后，通过 ×、窗口外部或 Esc 关闭均恢复原编辑位置和焦点，包括表格原生单元格；Preview 中返回设置入口。

## 输入候选弹窗

- 斜杠、文档、路径、标题及表情候选共用紧凑外框，继承编辑器字体、圆角、阴影、选中态和滚动条。斜杠左侧英文命令，右侧随界面语言变化的简短说明；表格命令用 `NxN` 提示可输入尺寸。
- 文档和路径使用双行选项：第一行显示名称，第二行左对齐显示路径，两行使用同样宽度；长内容省略显示，悬停提供全文。标题保持单行，右侧显示锚点以区分同名项；表情使用更窄的单行弹窗，左侧显示 `:name:`、右侧显示表情。匹配文字沿用强调色。
- 选中行背景贯穿弹窗宽度，左侧保留细双箭头标记的位置；匹配的斜杠和字母使用强调色，深色模式沿用标题蓝色。
- 滚动条始终预留同样宽度，轨道透明，仅悬停菜单时显示圆角滑块，整体裁切在弹窗圆角内。
- 以输入的 `/` 为锚点跟随文档滚动；空间不足时切换上下位置或缩短列表。锚点离开编辑区或单元格的可见范围时关闭，同一查询不因滚回而重新打开。
