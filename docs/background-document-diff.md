# 大文档后台差异计算

本轮重新开启已停止的跨模块性能改造。范围是 Source、Live 共用的 Git
差异链路，保留现有 CodeMirror 文本模型、Markdown 语法和编辑历史。

## 依据

`2cb1cbef` 的独立 CPU 诊断记录到换行后的派生刷新包含约 202ms 差异计算。
算法的 50ms 配置不包含所有分行和序列准备时间，也不能中断当前 JavaScript
任务。最终 `c900fbed` 正常原生运行的复杂文档输入仍出现约 1.28 秒峰值。
诊断样本与正常原生验收是两份证据，不能直接相减预测本补丁收益。

新增真实编辑器回归在修改前失败：大文档基线变更当场调用全文比较 1 次，
而该调用应为 0 次。该回归通过实际 Worker 验证最终差异，而非只把计算换成
定时器或模拟一个立即成功的结果。

## 约束与实现

- 沿用现有的大文档判断；普通文档仍同步返回差异，不创建 Worker。粘贴变大
  而智能判断尚未运行时，使用相同的字节/行数预算做无需扫描的下界检查；
  比较基线本身很大时也走后台，避免当前内容变小后仍同步处理大基线。
- 大文档把既有 `compareDocuments` 算法放入专用 Worker，保持原来的字符上限。
  后台沿用共享算法的 1 秒预算；普通文档在界面线程仍使用 50ms。没有改成
  更粗糙的差异算法，后台也不是无限计算。
- 编辑器最多保留一个在途任务。文本、基线改变或编辑器销毁时取消旧任务；
  正在计算的 Worker 会终止，空闲 Worker 可供下一次比较复用。
- 计算在既有输入与组合输入调度之后启动；发布也经过同一调度。结果同时
  校验文档对象与基线对象，过期任务不能覆盖当前文档。比较未完成时摘要为
  `pending`，原文恢复入口不会读取过期基线的差异。
- 单次计算有 5 秒外围期限。加载、运行或通信失败显示现有的不可用状态，
  不在界面线程同步回退全文比较。后续编辑或基线变化可以重新尝试。
- 已接受结果在模式间复用；只返回差异时不重新构建整篇 Live Markdown。
  已挂载表格更新行标记，新挂载表格通过文档归属明确的 Facet 读取结果。
- 表格结构命令使用当前状态中的行映射；需要复用控件中的位置投影时，
  同时核对其基线身份。固定回归曾分别重现“新基线尚未返回”和“结果已
  返回但控件尚未更新”两种竞态，旧行号会额外生成空行或分隔行的原文块。
  两条路径现均拒绝旧映射，不把呈现缓存当成当前历史数据。
- 差异行数按已接受数组缓存；读取摘要不再反复扫描所有行。

Worker 单独打成一个经典脚本，通过扩展资源 URI 获取后创建 Blob Worker。
CSP 只增加扩展资源连接和 Blob Worker，未开放任意网络脚本或动态执行。
这是 [VS Code 官方 Webview Worker 文档](https://code.visualstudio.com/api/extension-guides/webview#using-web-workers)
要求的资源加载方式。实际 VSIX 检查必须包含该脚本。

## 验证与限制

`bun scripts/test-git-diff-background.ts` 覆盖真实后台结果、输入后 pending、
过期取消、撤销、组合输入、模式复用、远处表格首次挂载、Worker 失败和普通
文档即时摘要。测试在后台只返回差异时同时禁止整篇 Live 重建。
`test-live-decoration-history.ts` 保留现有的正文、复杂格式、表格映射和历史
对照，并等待真实差异发布，避免把编辑呈现结算误当成后台计算已完成。

本改造并未搬走代码配色、全部 Markdown 解析或首次预览渲染。是否达到实际
交互门槛，仍须以当前候选在固定虚拟机的原生验收判断。不能从“主线程比较
次数为零”推断点击、输入、拖动和冷启动已经全部达标。

`00f24dd7` 的首轮正常原生运行没有通过：普通样本 Live 输入最高约 510ms，
综合样本停在真实差异发布检查，不能把缺少的后续行为算成功。该轮宿主机
启动时约 237MiB 空闲，虚拟机仍为 6GiB、4 核、回收参数 0；没有据此归因。
随后用独立配置、未改动的产品 JavaScript 观察 Worker，记录到最终请求
约 453ms 后返回 `hitTimeout=true`，界面明确显示比较超时。加载和后台请求
实际成功，不是从浏览器小样本通过推断原生环境也正常。

因此后台不再沿用界面线程的 50ms 预算，改用上述 1 秒共享预算；取消和
5 秒外围期限继续生效。真实 Worker 回归在请求期间固定推进算法时钟，
先重现超时，再要求返回真实的单行修改结果。该诊断不作为性能验收，新的
正常原生结果另行记录。
