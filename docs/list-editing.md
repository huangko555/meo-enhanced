# 列表编辑规则

有序、无序和任务列表共用条目前缀规则。一个条目由容器与缩进、列表标记、可选任务状态、
分隔空白和正文组成。编辑修改原始 Markdown，Live 将同一前缀投影为编号、圆点或勾选框。

## 前缀与状态

| 内容 | 规则 |
| --- | --- |
| 无序标记 | 接受 `-`、`+`、`*`，续项保留当前符号 |
| 有序标记 | 接受数字加 `.` 或 `)`，续项递增，保留分隔符 |
| 任务状态 | 有序、无序项均可附加 `[ ]`、`[x]`、`[X]`，分别表示未完成与已完成 |
| 其他方括号 | `[~]`、`[-]`、`[/]` 等属于正文 |
| 未完成输入 | 尚无分隔空白的标记保留可编辑源码，任务前缀在状态后的分隔空白完成后生效 |
| 容器 | 语法所有者判断引用、列表、脚注和代码等归属，前缀识别只读取调用方给定的当前行与偏移 |

`src/foundation/markdownListPrefix.ts` 提供共同的源码前缀与偏移。
编辑命令、Live 标记和块插入使用它，字体宽度、DOM、语法树与历史留在编辑器适配器。
完整 Markdown 和 HTML 的语义来源见[内容规则](content-policy.md)。

## 编辑动作

| 动作 | 规则 |
| --- | --- |
| 空条目回车 | 清除该项的缩进、标记和任务状态，保留外层引用前缀 |
| 正文开头回车 | 在原条目前插入同级空项，光标留在新空项中 |
| 正文末尾回车 | 在原条目后续项，任务状态重置为未完成 |
| 正文中间、选区或多光标回车 | 由既有 Markdown 键盘命令处理拆分与替换 |
| 正文起点退格 | 去除当前项前缀，已有子项按现有缩进规则提升；删除空项后恢复有效正文位置 |
| 行末 Delete | 下一行为空列表项时，一次删除换行及该项完整前缀，光标留在当前行末 |
| 缩进与反缩进 | 使用当前连续列表段已有的两空格、四空格或制表符风格，作用于选中行 |
| 列表类型转换 | 统一块命令替换完整前缀，保留正文与缩进；重复应用当前类型时移除该前缀 |
| 任务完成命令 | 只切换状态字符，有序与无序任务使用相同两态规则 |

代码、公式、HTML、frontmatter、表格原生输入与输入法继续由各自输入所有者接管。
列表动作沿用现有输入辅助开关、只读和选择规则。

## 选择、勾选与历史

- 编号或圆点后的空白属于正文选点入口，鼠标按下后建立固定拖选锚点。
- 按住鼠标期间使用已接受的前缀呈现，完整的拖动、松开和取消交接由既有指针所有者完成。
  普通正文选区保留标记，精确编辑前缀时允许揭示源码。
- 鼠标勾选时，光标已在该任务正文内则保留位置，否则同一次事务移到正文起点。
  键盘激活勾选框时保留控件焦点。
- 文本、完整定向选区和列表语义位置随同一次原生历史事件保存。撤销、重做以及新的输入
  使用现有历史、焦点和视口所有者。

## 编号与性能

- 编号归一化只访问变更邻近的连续列表段。同级后续编号递增，嵌套段保留明确的起始编号，
  显式缩进命令沿用原有重置规则。外部文档呈现和原生历史回放拥有其内容。
- 前缀识别只处理行字符串，连续段发现使用无呈现对象的快速前缀检查。
- 普通正文编辑不进入无关列表扫描。巨型单个列表的工作量由受影响列表段决定，
  不以固定等待或同步全文解析换取首帧正确。
- 输入立即接受文本与选择。新条目前缀沿用已接受行的布局，经过现有有界局部投影，
  完整结构由后台解析和派生刷新确认。
- 未改装饰、控件、DOM 和阅读锚点沿用既有映射与窗口投影。任务勾选只改变对应状态，
  后台完成继续校验当前版本与生命周期。

性能所有者、局部容量和失效条件遵守[编辑性能合同](editor-performance-contracts.md)。

## 维护与验证

共同前缀规则只维护在 `markdownListPrefix.ts`。回车只进入 `handleEnterInList`，
工具栏与快捷键只进入现有块命令。新增行为先明确所属规则及所有者，再扩展对应合同。

| 合同 | 保护范围 |
| --- | --- |
| `test-ordered-list-renumber.ts`、`test-ordered-list-work-bound.ts` | 前缀、两态任务、编号语义与 50,000 行工作量负对照 |
| `test-list-layout-interaction.ts` | 原生回车与删除、拖选、中间帧、未改节点身份、历史、普通与实际优化路径 |
| `test-list-editing-transaction.ts`、`test-list-transaction-composition.ts` | 单次文档接受、原生事务合成、IME 与历史 |
| `test-live-composite-lists.ts`、`test-list-toolbar-browser.ts` | 引用和嵌套、控件命中、类型转换、字形与焦点 |
| `test-editing-features-production.ts`、`test-slash-commands-production.ts` | 任务命令、受保护输入及列表内块插入 |

按[日常修复与文档规模流程](testing-workflow.md#daily-repair-loop)选择相关合同。
结构与性能改动同时保留普通文档、大文档、实际优化路径、完整内容及中间帧证据。
