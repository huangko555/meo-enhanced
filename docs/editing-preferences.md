# 设置与输入辅助

在右上角设置菜单选择“更多设置”，打开“常规 / 输入辅助 / 快捷键”。左侧章节可以跳转，正文也可以连续滚动；搜索会筛选三个分类。设置保存成功后同步到其他面板，重新打开仍会保留。

小菜单保留常用文档显示选项及主题、语言、字号。行号开关控制左侧行号栏；工具栏“行号”用于跳到指定行，二者独立。

## 输入辅助

- 选中文字后输入符号可以包裹选区。覆盖 VS Code 原生 Markdown 的全部 11 组：`()`、`[]`、`{}`、`<>`、单双引号、反引号，以及 `*`、`_`、`~`、`$`；另外支持 `（）【】“”‘’《》「」『』`。内部文字保持选中，反向选区方向保留；连续输入可得到 `**文字**`、`__文字__`、`~~文字~~`、`$$文字$$` 和双反引号。内容中已有反引号时自动使用更长的界符；无选区时连续输入三个及以上反引号保留代码围栏。
- 包裹与空光标补全独立：新增的 `*`、`_`、`~`、`$`、`<>` 只包裹选区，不自动补出另一半，也不触发空对跳过或成对退格。选区前的反斜杠不阻止包裹。纯空格/Tab/换行选区、用英文引号替换单个引号/反引号，或多选区中存在不能包裹的选区时，整次输入按普通替换处理。规则参照 [VS Code Markdown 配置](https://github.com/microsoft/vscode/blob/645f29c/extensions/markdown-basics/language-configuration.json#L45-L90) 和 [原生选区包裹逻辑](https://github.com/microsoft/vscode/blob/645f29c/src/vs/editor/common/cursor/cursorTypeEditOperations.ts)。
- 补全、跳过和空对退格分别配置。默认按上下文补全，只跳过/删除自动插入的符号；“始终插入”和“只删除一个字符”保留逐字输入习惯。输入法预编辑期间不改写，确认后再处理；输入法已补整对时不重复。
- 列表和任务项默认按 Enter 续写，空项再按 Enter 退出。关闭后换行保留普通输入行为；表格内换行使用当前绑定的“单元格内换行”。
- 文档、路径、标题候选出现在 Markdown 链接或双链语境；标题候选支持井号标题、下划线标题及重复标题的独立锚点。标题查询对当前文本限制为 2,000,000 字符，外部文件限制为 2,000,000 字节。空段落输入 `/` 可以选择常用块。表情名称候选默认关闭，开启后输入 `:name` 并选择才替换成 Unicode；未选择的 `:smile:` 保留原文。

## 复制与粘贴

| 位置/来源 | 行为 |
| --- | --- |
| 正文 + Excel/TSV/HTML 表格 | 开启表格转换时插入 Markdown 表格，第一行作为表头；关闭时保留文本 |
| 已有表格 + 表格矩阵 | 从当前单元格覆盖并按需扩展；此行为独立于正文转换开关。支持编辑器自有格式、HTML、TSV 和 Markdown 表格源码 |
| 代码块或行内代码 | 保留文本，避免链接、HTML、表格转换 |
| 选中文字 + 网址 | 开启链接选项时用选中文字作为链接名称 |
| 正文 + 常见 HTML | 开启格式选项时转换支持的标题、列表、引用和行内格式；纯文本粘贴跳过转换 |
| CSV 文本 | 选择文本后执行“转换选中表格文本”，不自动猜测正文中的逗号 |
| 多选区 | 使用普通文本粘贴分发到各选区 |

普通表格复制同时提供文本、HTML 和编辑器自有数据，供不同目标选择。显式“复制为 Markdown 表格 / CSV”复制选区或当前表格的单元格源码；CSV 引号、换行和分隔符按 CSV 格式编码。HTML 合并单元格展开为空白占位，内容保留在合并区域左上格。批量表格操作上限为 10,000 个单元格，剪贴板解析上限为 5,000,000 字符。

## 快捷键

快捷键分为文档、文字格式、段落、表格、选择、行操作、模式导航。除复制/剪切/粘贴和基础导航等系统规则外，可录入组合键、清除或恢复默认。未设置的命令可以自行绑定。

录入时 Enter 确认、Esc 取消，Tab 正常移动焦点；带修饰键的 Enter/Esc 可以作为组合键。冲突会列出原命令，必须明确点击“替换原绑定”。恢复默认只重置快捷键，其他偏好保留。工具栏和选中文字菜单提示随绑定更新。

默认粗体、斜体使用 Ctrl+B / Ctrl+I，macOS 使用 Cmd+B / Cmd+I；撤销、保存、查找等跟随平台习惯。表格专用命令只在表格内执行，块和行命令在文档编辑区执行。Preview 和设置/查找输入框不会触发正文格式修改。操作系统或 VS Code 先处理的组合键可能无法传到 Webview，应选择其他组合。

Windows 上在 Live / Source 文档编辑区单按左 Alt 会保持光标，不进入 VS Code 菜单栏；菜单仍可用鼠标打开。Alt 组合快捷键、右 Alt / AltGr、输入法和设置输入框保留原有处理，不新增配置。

这些设置位于 `meoEnhanced.editing.preferences`。已有工作区配置时更新该工作区，否则更新用户配置；多面板共享一个保存所有者，按字段合并并防止旧回执覆盖新值。
